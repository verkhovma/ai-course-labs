## Быстрый старт
```bash
# Клонирование
git clone https://github.com/verkhovma/ai-course-labs.git
cd ai-course-labs
# Опционально (рекомендуется) - создание и активация виртуального окружения
python3 -m venv venv
source venv/bin/activate
# Переход к конкретной работе
cd week1
# Установка зависимостей
pip install -r requirements.txt
# Запуск
python3 src/agent_core.py
```
